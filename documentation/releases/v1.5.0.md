# SweetCherry 1.5.0

SweetCherry is an open-source web companion for CherryTree CTB note databases. This release makes first-time setup, finding notes and everyday navigation more convenient, with Quick switch/Quick note, improved advanced search, saved filters and backlinks.

## Download and install

Windows 10/11 **64-bit** packages include **Java 17**; a separate Java installation is not required.

| Asset | Purpose |
| --- | --- |
| `SweetCherry-1.5.0-windows-x64-setup.exe` | Installation wizard, desktop launcher and shortcuts. Choose a writable folder. |
| `SweetCherry-1.5.0-windows-x64.zip` | Portable application. Extract the complete folder before running `SweetCherry.exe`. |
| `SweetCherry-1.5.0-notices.zip` | Third-party licenses and attributions, also included in both application packages. |
| `SHA256SUMS.txt` | Checksums for the installer, portable ZIP and notices ZIP. |
| `windows-bundle.json` | Application version, exact build commit and bundled Java information. |

GitHub's automatic Source code ZIP/tar.gz archives contain source, not a ready-to-run application. Linux/Raspberry Pi source builds require **JDK 17 or newer**, not only a JRE. The Windows EXE and bundled Windows Java cannot run on Linux. Linux has launcher/shortcut scripts; macOS scripts remain unverified on a physical Mac.

## New in 1.5.0

- **Easier first start:** create missing external YAML files without overwriting existing ones, default fresh readers to the desktop tree, and use Greenwich astronomy defaults. Local launcher controls can copy the administrator password; the login page explains where to find it. Generated initial passwords may be shown once in the local console according to configuration.
- **Linux convenience:** detached desktop launching and per-user application-menu/desktop shortcuts; an unprivileged default main port. A source build needs a full JDK. Existing external settings remain in effect.
- **Quick switch and Quick note:** find titles with styled occurrence results and keyboard navigation, or capture a plain-text/Markdown note with searchable parent selection and remembered per-source destinations. Creating notes requires ADMIN and a writable database.
- **More useful advanced search:** match all words, any word or a phrase across titles/raw content, combine whole tags with ANY/ALL, choose tags/icons from searchable lists, sort columns, and see occurrence breadcrumbs under names. Keep POST submission, stable pagination, editable page size and current-page PDF export.
- **Saved filters:** save, update, apply and delete private presets per user/source outside CTB. New matching and sorting settings are included; older presets remain readable.
- **Backlinks:** open an incoming-link panel beside the desktop reading area or above mobile content, with source navigation, link labels, IDs and breadcrumb tooltips. Choose an exact target occurrence or all occurrences sharing its content. Tree content keeps its independent scrollbar.
- **Updated icons and bookmarks:** add CherryTree icon IDs 246–263 with their original SVG and resized PNG files, preserving earlier IDs and the existing code-language mappings. Bookmarks show node Created and Modified dates, with compact mobile presentation.

## Upgrade from 1.4.0

Stop SweetCherry and back up your CTBs, tenant configs, external YAML files, login-credentials.properties, exports and private saved-filters folder if present. Extract/install into a separate writable folder and deliberately copy your data/configuration across. Do not overwrite notes/passwords with demo files or merge old/new Java runtime folders. Existing external YAML takes precedence; missing files are initialized from packaged defaults.

Saved-filter scope includes user, connection identity and application working directory. Moving the installation or changing a connection can create a new scope; copying saved-filters alone does not guarantee that old presets appear under the new identity. Saved search text may be sensitive: do not include your private preferences or credentials in shared packages.

**SweetCherry does not create automatic backups.** Do not write to the same CTB simultaneously from SweetCherry and CherryTree. SweetCherrySync is separate; synchronization can overwrite edits to its target. No CTB schema change is required by these new features.

## Validation and limitations

The maintainer reported **611 passing Java tests** and successful manual bookmark/icon checks on feature commit `6b9f558491e374e125cc6c494a7d587f73eb7982`; Quick switch/Quick note, saved filters/backlinks, scrolling and advanced search had also been manually checked. Linux first-start/launcher/shortcut behavior was verified with JDK 21. Build and check the Windows packages from the final **v1.5.0 tag** before publication; this note does not claim the release workflow has already run.

Advanced search still examines **raw node.txt**, including rich-text XML metadata. It is not full-text indexing or rendered-content search; database LOWER/LIKE and collation behavior apply. Empty date bounds include future calendar nodes. Search results are tree occurrences, so shared content can appear in multiple positions; orphan node records without a tree occurrence are excluded. Existing large page sizes remain available and can produce large pages/PDFs.

Backlinks inspect supported CherryTree rich-text/object internal links, not Markdown /nodes/ID URLs. Scans are on demand and bounded; warnings indicate incomplete/unreadable contents. Saved filters are personal preferences, not database records or backups. Initial browser permissions and clipboard formats still vary; some actions need HTTPS/localhost, and Flameshot compatibility remains unresolved.

Existing editor recovery, Markdown and synchronization limitations from 1.4.0 remain. The isolated MariaDB 1020 conflict remains an observation if it recurs. Two previously reproduced duplication JavaScript test failures are separate test-maintenance items and are not included in the passing Java test count.
