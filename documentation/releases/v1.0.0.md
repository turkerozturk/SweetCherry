# SweetCherry 1.0.0

SweetCherry is an open-source web companion for CherryTree CTB note databases. Access your notes through desktop and mobile browser views, edit supported content, and export it in useful formats.

## Download and install

Windows 10/11 **64-bit** packages include **Java 17**. A separate Java installation is not required.

| Asset | Purpose |
| --- | --- |
| `SweetCherry-1.0.0-windows-x64-setup.exe` | Installation wizard and shortcuts. Choose a writable folder. |
| `SweetCherry-1.0.0-windows-x64.zip` | Portable package. Extract the complete folder before starting `SweetCherry.exe`. |
| `SHA256SUMS.txt` | SHA-256 checksums for the installer and portable ZIP. |
| `windows-bundle.json` | Bundled runtime and build information. |

[English installation guide](https://github.com/turkerozturk/SweetCherry/blob/v1.0.0/documentation/en/setup-and-run.md) · [Türkçe kurulum kılavuzu](https://github.com/turkerozturk/SweetCherry/blob/v1.0.0/documentation/tr/installation.md)

The Windows control window shows startup progress and provides browser, application-folder, log and shutdown controls. Initial account passwords are stored in `login-credentials.properties` in the application folder. The included demo database lets you explore the application without using your own notes.

GitHub's **Source code** archives are source packages, not ready-to-run applications. Linux and other Java environments can build from source with JDK 17 or newer; see the installation guide. No Windows 32-bit package is included.

## Highlights

- Desktop and mobile readers, bookmarks, search and shared-node hierarchy.
- Plain/rich-text editing, image and file insertion, external links, tables and formatted web-page paste.
- Node movement, duplication, sibling/child creation and shared-node operations.
- Markmap and Mermaid views; Freeplane/FreeMind export, including optional CherryTree icon bundles.
- Node and subtree PDF export with embedded fonts, clickable links, hierarchical PDF bookmarks, optional contents, page/layout options and object inclusion controls.
- Four CTB export choices for individual nodes and subtrees, including shared occurrences.
- Configurable HTTP/HTTPS and trusted-proxy support, documented separately. Optional offline sun/moon information.

## Before using your own notes

**SweetCherry does not create automatic backups.** Keep a separate backup of important CTB files before editing. Avoid simultaneous writes from CherryTree and SweetCherry. Copying a stopped portable application folder only backs up data stored inside that folder; externally located CTB files need their own backup.

Content search currently searches the raw stored text. Browser Back after a POST search may request form resubmission. CTB export preserves the exported hierarchy and supported shared relationships; node IDs embedded in text links are not rewritten. Codebox editing and some further editor refinements remain follow-up work. macOS scripts have not been verified on a physical Mac.
