# SweetCherry 1.4.0

SweetCherry is an open-source web companion for CherryTree CTB note databases. This release adds Markdown rendering and editing, internal-link tools, tags, calendars, and browser-local editor recovery.

## Download and install

Windows 10/11 **64-bit** packages include **Java 17**; a separate Java installation is not required.

| Asset | Purpose |
| --- | --- |
| `SweetCherry-1.4.0-windows-x64-setup.exe` | Installation wizard, desktop launcher and shortcuts. Choose a writable folder. |
| `SweetCherry-1.4.0-windows-x64.zip` | Portable application. Extract the complete folder before running `SweetCherry.exe`. |
| `SweetCherry-1.4.0-notices.zip` | Third-party licenses and attributions, also included in both application packages. |
| `SHA256SUMS.txt` | Checksums for the installer, portable ZIP and notices ZIP. |
| `windows-bundle.json` | Application version, exact build commit and bundled Java information. |

GitHub's automatic Source code ZIP/tar.gz archives contain source, not a ready-to-run application. Linux/Raspberry Pi users can build with JDK 17 or newer. The Windows EXE and bundled Windows Java are not Linux binaries. macOS scripts have not been verified on a physical Mac.

## New in 1.4.0

- Render Markdown nodes in desktop/mobile readers, calendar previews, templates and PDF exports; edit their source with formatting tools and optional live preview. Markdown inside embedded codeboxes remains code.
- Create and edit rich-text internal links by node ID or exact selected-title matches, with styled target choices and existing-anchor selection.
- Inspect internal links in a searchable report with source/target navigation, breadcrumb tooltips, statistics and validity diagnostics.
- Edit node tags with a searchable multi-select picker and browse matching nodes in a Tags view with ANY/ALL filtering.
- Browse Created dates in weekly/monthly calendars with tag filters, mobile day lists, content previews and guarded date editing. Changing Created also updates Modified; shared occurrences use their original node's timestamps.
- Recover unsaved plain-text, rich-text and Markdown edits from browser-local drafts, including supported editor history and staged objects. Failed saves keep the editor open.

## Upgrade from 1.3.0

Stop SweetCherry and back up your CTBs, tenant configs, external YAML, login-credentials.properties and exports. Extract/install into a separate writable folder and deliberately copy your data/configuration across. Do not overwrite notes/passwords with demo files or merge old/new Java runtime folders. Existing external YAML still takes precedence; omitted settings use defaults.

**SweetCherry does not create automatic backups.** Do not write to the same CTB simultaneously from SweetCherry and CherryTree. SweetCherrySync is separate; synchronization can overwrite edits to its target.

## Validation and limitations

The maintainer reported 572 passing Java tests and successful manual Markdown editor/viewer checks on feature commit `39003c72e32b98ec938e8f1dbc83ddd8b2c3c044`. Build and check the Windows packages from the final **v1.4.0 tag** before publication; this note does not claim that the release workflow has already run.

Recovery drafts are local browser data, not database autosave or backups; they are not encrypted and are subject to browser storage limits, retention and clearing. Manual Save and continue reloads the editor and resets its undo history. Calendar date editing changes the original node's timestamps for all linked shared occurrences; it does not create a separate scheduling database or update SweetCherrySync code.

Markdown raw HTML is escaped and rendered output is sanitized. Markdown source is preserved; raw-content search remains unchanged. Node rendering/preview is limited to 2,000,000 characters. Remote Markdown images are not downloaded for PDF. Markdown `/nodes/ID` URLs are not CherryTree internal-link objects and are not ID-remapped during CTB import/export. Existing anchors can be selected when editing rich-text links; creating new anchors is not added in this release.

Existing limitations remain: clipboard formats and permissions vary by browser, some clipboard actions require HTTPS or localhost, Flameshot compatibility remains unresolved, and macOS scripts have not been verified on a physical Mac. The isolated MariaDB 1020 conflict remains an observation if it recurs. Two previously reproduced duplication JavaScript test failures remain separate test-maintenance items; they are not part of the passing Java test count.

SweetCherry is GPL-3.0-or-later. Third-party licenses, including Flexmark notices, are included in the Windows packages and notices ZIP.
