# SweetCherry 1.8.0

Prepared on **11 November 2026**. Final packages from the release tag must be checked before publication. SweetCherry is an open-source web companion for CherryTree CTB note databases.

## Downloads and platforms

| Asset | Purpose |
| --- | --- |
| `sweetcherry_1.8.0_all_os_portable.zip` | Complete portable application and Windows/Linux/macOS scripts, **without Java**. Requires Java 17+ matching the OS/CPU. |
| `sweetcherry_1.8.0_all_os_portable_with_java_and_setup.exe` | Windows x64 setup/extraction wizard, complete application folder, bundled Windows Java 17 and optional shortcuts. |
| `sweetcherry-1.8.0-third_party_licences.zip` | Third-party licences and attributions, also included in both application packages. Optional separate download. |
| `sha256sums.txt` | SHA-256 checksums for the three product files above. |

The Java-free ZIP is intended for Windows/Linux, including Raspberry Pi ARM with a matching Java installation. macOS scripts are included; **macOS and 32-bit/i386 systems remain untested**. Native SQLite/JDBC support and compatible Java are required. The EXE and its bundled Java are **Windows x64 only**, despite the `all_os` filename. A Java JAR alone does not guarantee support for every OS/CPU combination.

Extract the entire ZIP. Use `run.bat` on Windows, `sh ./launcher.sh` on Linux desktop, `sh ./run.sh` on Linux/Raspberry Pi terminals, or `sh ./run.command` on macOS. Windows ZIP users should use `run.bat`; the retained `SweetCherry.exe` needs the runtime provided by the Windows setup package. Linux desktop shortcuts can be installed with `sh ./install-desktop.sh`.

`build-info.json` remains inside both packages and records the version, exact source commit and Windows packaging provenance. It is not a separate asset. GitHub provides Source code archives automatically.

## New since 1.7.0

- **Freeplane/FreeMind MM import** (`cdf13fc`): preview a map and import its hierarchy, titles and readable note/details content into a new final root branch. Supported title formatting, timestamps and SweetCherry icon references are retained. Original CTB IDs and data absent from the exported MM cannot be reconstructed; enable note-content export when a content round trip is needed. [Guide](../en/freeplane-import.md).
- **HTML notes and source editor** (`6764077`): select HTML directly in Node Properties, edit source beside a live preview and read rendered HTML in content views. Undo/redo, Save and continue and draft recovery use the existing editor workflow. Original HTML source is stored unchanged; jsoup sanitization and sandboxed readers limit displayed content. This is a source/preview editor, not a WYSIWYG editor. [Guide](../en/html-notes.md).
- **ZIP folder/file import wizard** (`313b9d8`): preview and append a folder tree as new database roots. Text extensions select canonical syntax/icon mappings, including `.md` → Markdown and `.py` → Python. Optional extension removal, binary attachments and oversized-file information nodes are supported. Imports are transactional. [Guide](../en/zip-import.md).
- **Create empty CTBs** (`345dd38`): the data-source wizard can create a modern, empty SQLite CTB in `CTBDATA` and register its connection. Portable filenames, case/normalization collisions, SQLite sidecars and existing tenant references are checked. Failed schema/configuration creation cleans up the new CTB. Windows file-URI comparison is corrected. [Guide](../en/empty-ctb.md).
- **Translated utility pages and map close buttons** (`f9d0816`): data-source uploads, outcomes/errors and session information use the selected language. Session date formatting is corrected. Both quick mind-map pages have close controls; Markmap retains its close control in page-filling mode. If the browser refuses to close the tab, the control returns to the home page.
- **Documentation and release preparation** (`b4a45b8` and this preparation): README download/setup links and feature tables, a link to automatically generated DeepWiki documentation, updated installation guides and current release notes. The duplicate-command JavaScript fixture now includes the shared-copy form field and follows the supported shared-root subtree behavior; production duplication behavior is unchanged by this preparation.

## Upgrade and source builds

Stop SweetCherry. Preserve your CTBs, external YAML, all tenant configuration files, credentials, exports, saved filters and complete backup directories. Use a separate writable application folder for the new release and deliberately transfer your own data/settings. Avoid replacing private data with bundled demos or carrying an old Java runtime into the new installation. Existing external configuration takes precedence; review writable flags before editing notes.

No existing CTB schema migration is required by this release. The new empty-CTB option creates a separate database; it does not replace an existing file. Explicit legacy-schema upgrade permissions retain their existing behavior. Imports and edits write data and require ADMIN plus a writable connection/node where applicable. Tenant creation is ADMIN-only.

Build the release tag with **JDK 17+** using the Maven wrapper, then use the **entire generated `release/SweetCherry` folder**. GitHub Source code ZIP/tar.gz archives are source, not prepared portable distributions. Building requires initial internet access for dependencies. Keep the run scripts, data/configuration folders, documentation and licence files together.

The separately updated English practice workbook previously attached to 1.7.0 remains available through its existing README link. Preserve exercises already completed before replacing a workbook. This release preparation does not silently replace that workbook or the application's sample CTBs.

## Limits and validation

- MM import reads an unencrypted `.mm` XML file, not an MM inside a ZIP. Notes/details become readable text; unsupported Freeplane-specific features are reported or retained as inert descriptions. It is not a lossless interchange format for all CTB objects.
- HTML display supports note formatting and basic inline styles. Scripts, forms, frames, stylesheets and external resources are omitted. Use embedded raster images. Preview/render/save source is limited to 2,000,000 characters.
- ZIP imports respect configured upload/request limits and per-database attachment limits. Additional limits are 256 MB compressed archive size, 10,000 entries/resulting nodes, 64 levels, 2,000,000 bytes per text file, 64 MB of decompressed file data read and 32 MB of retained content. UTF-8 ZIP member names and supported text encodings are required; encrypted archives are unsupported. Oversized-file dates/sizes come from ZIP metadata, with unavailable dates stated explicitly.
- Portable filename collisions and existing/dangling tenant references prevent empty-CTB creation. `CTBDATA` itself must not be a symbolic link. Existing connection editing remains separate from database creation.

The maintainer reported **759 passing Java tests** and successful manual verification before this preparation, including the Windows URI fix and empty-CTB creation. This preparation still needs the final Windows/Linux CI and tagged Windows distribution workflow checks before publication. Any local preparation checks are recorded separately; they do not establish that the final EXE or every supported platform was tested.

Existing editor, database, PDF and concurrent-write limitations continue to apply. Keep independent backups and avoid simultaneous writes from SweetCherry and CherryTree. Read-only copies are useful for initial upgrade checks.

SweetCherry is GPL-3.0-or-later. `LICENSE`, `THIRD-PARTY-NOTICES.md` and `licenses/` remain inside both product packages; the separate licences archive is a convenience copy.
