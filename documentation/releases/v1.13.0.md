# SweetCherry 1.13.0

Prepared on **21 November 2026**. This release adds an offline, read-only Draw.io attachment viewer, reusable inline icons and more comfortable content editing. Java **17+** and the existing CTB schema are retained.

## Changes since 1.12.0

- Added a read-only multi-page Draw.io attachment viewer with page selection, fullscreen, scrolling, zoom, page fit and horizontal fit.
- Improved Draw.io compatibility with generated root/layer IDs, ports and blank pages, and added localized parsing diagnostics.
- Added configurable diagram size, page, cell and XML limits through YAML and System settings.
- Preserved supported label wrapping, alignment, line breaks and foreground/background colors.
- Bundled local stencil and icon libraries with configurable families, including networking, Cabinets and EIP definitions.
- Added meaningful, hideable missing-shape/image labels and optional administrator-provided PNG/JPEG replacements.
- Made wheel zoom follow the pointer, and enabled validated internal-page and external HTTP/HTTPS links.
- Added a filtered picker for Unicode characters, CherryTree icons and installed Font Awesome styles, with copy and insertion actions.
- Added display-only icon markers in node names and rich-text content, including maps, graph labels, lists and PDFs.
- Removed recognized icon markers from generated export filenames while preserving stored CTB names and export contents.
- Added remembered editor text zoom, end-of-content startup and blank writing space below the final line.
- Reorganized rich-text history, alignment, object-safety and other tools into more compact groups.
- Fixed Windows CRLF library tests and binary font resource copying during Maven packaging.
- Added an optional external replacement-folder template, bundled diagram examples and release checks for offline resources and private-file exclusion.

## Offline resources and customization

Draw.io viewer code, the packaged shape/icon definitions, CTB icons and symbol catalogues are inside `SweetCherry.jar`; Font Awesome browser fonts are in its existing WebJar and PDF icon fonts are embedded local resources. No first-run download or manual shape-library installation is needed. Packaged artwork retains its individual upstream terms; the included licences do not imply that every symbol or brand is unrestricted.

The new external `drawio-images/` folder contains a README and a comment-only `images.properties` template. It is **optional and disabled by default**: set `myapp.drawio-preview.local-images-directory` to the folder's absolute path and restart to use your own mappings. Mappings/images are application-wide; put only images intended for relevant readers there. This folder needs a separate backup. Maven preparation and Windows setup create seed files only when absent, preserving existing user files. ZIP tools have their own overwrite behavior: extract into a new folder. Clean release checks reject edited mappings or extra/private images.

Both packages include Draw.io guides and the two `.drawio` examples under `documentation/examples/`. The tagged workflow checks the actual application JAR and the extracted Java-free ZIP for complete, byte-identical resources, including the three PDF fonts; the installer smoke test checks that an existing replacement map and image survive installation.

## Upgrade and behavior

Stop SweetCherry and other CTB writers, back up databases, external configuration, tenants, credentials, saved filters and optional replacement images, and install/extract into a new writable folder. Transfer private data deliberately. Existing external YAML overrides bundled defaults. No CTB schema migration or new Maven dependency is introduced.

- The Draw.io preview does not upload diagrams or automatically fetch external pictures. Explicitly clicked web links open their original website in a separate tab; internal links select another page in the same diagram. Unsupported/custom shapes and advanced Draw.io behavior can differ from the original application.
- Diagrams remain read-only. XML/geometry budgets, sanitization, sandbox and restricted resource access remain active; the viewer is not the full Draw.io editor.
- Icon markers such as `{{fa-solid fa-image}}` and `{{ctb:ct_camera}}` remain ordinary stored text; CherryTree desktop and text/mind-map export contents retain them. Unknown expressions are not evaluated. Native browser titles/tooltips/select options use readable labels; Unicode appearance still depends on fonts.
- Editor zoom is separate from reader zoom and does not change stored font formatting or undo history. Initial scrolling yields to a changed selection or restored recovery draft; writing padding adds no saved blank paragraphs.
