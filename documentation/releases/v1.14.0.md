# SweetCherry 1.14.0

Prepared on **25 November 2026**. This release adds a configurable reading workspace, optional DailyTopicTracker integration and more portable application settings while retaining Java **17+** and the existing CherryTree CTB format.

## Downloads

| Asset | Purpose |
| --- | --- |
| `sweetcherry_1.14.0_all_os_portable.zip` | Complete application and Windows/Linux/macOS scripts without Java; requires a matching Java 17+ runtime and native SQLite dependencies. |
| `sweetcherry_1.14.0_all_os_portable_with_java_and_setup.exe` | Windows x64 setup/extraction wizard, launcher and bundled Windows Java 17. |
| `sweetcherry-1.14.0-third_party_licences.zip` | Third-party notices and licences, also included in both application packages. |
| `sha256sums.txt` | SHA-256 checksums for the three assets above. |

Use the complete application folder. The installer and bundled runtime are Windows-only despite the `all_os` filename; macOS and 32-bit/i386 remain untested.

## Changes since 1.13.0

- Added a remembered reading layout with compact icon buttons and independent visibility controls for the main menu, node title, breadcrumbs, backlinks, node actions and split-pane controls.
- Added independently switchable tree node IDs and dates with configurable zero padding, date formatting and creation/modification timestamps.
- Added quick editing of node names and CherryTree icons with a searchable icon chooser and smaller symbol, save and cancel controls.
- Added clearer shared-node and master-node styling plus clipboard actions for node IDs and node text.
- Added a confirmed Empty Trash action that processes all trash entries together while preserving shared content outside the trash.
- Added an optional DailyTopicTracker bridge for viewing and editing dated topic entries, statuses and notes from linked SweetCherry nodes.
- Added DTT topic descriptions, category/group links, recurrence information, latest completion dates and predicted dates to the node panel.
- Added full and incremental DTT topic imports that preserve the group/category hierarchy and create topic-linked CTB nodes.
- Added tenant-wizard DTT connection settings and separate connection tests for the SweetCherry database and the DTT bridge.
- Made saved searches portable with the application folder and added non-overwriting migration for legacy preference files.
- Updated the Windows launcher to prefer an adjacent runtime and fall back to compatible 64-bit system Java 17 or newer.
- Removed launcher and run-script port overrides so external YAML controls HTTP/HTTPS endpoints, with a desktop protocol/port prompt when no external port is specified.
- Added preserved saved-filters and backup directories, a local launcher build helper and expanded packaging and PowerShell checks.

## Upgrade notes

Stop SweetCherry and other CTB writers before upgrading. Back up CTBs, external YAML, `allTenants`, credentials, `saved-filters`, `backup` and any custom `drawio-images` mappings/images. Extract into a new writable folder and transfer private files deliberately; ZIP extraction follows the archive tool's overwrite rules. No CTB schema migration is required, and DTT remains a separate optional application.

- Reading-layout preferences are stored in the browser; the title is visible by default, and tree IDs/dates are initially hidden unless configured otherwise.
- Quick icon changes preserve content, lock, color and boldness; the full Properties page remains available.
- Empty Trash permanently removes every trash entry after explicit confirmation, including entries on other pages; it retains shared content that has surviving locations outside the trash.
- The DTT bridge needs a compatible DTT server with the bridge API and a matching token supplied through the environment; imports require an ADMIN user and a writable target CTB.
- Saved searches now use an installation-independent namespace for ordinary SQLite files under the application folder; login name, tenant name and relative database path must still match.
- For legacy saved searches, first open the new version in the original application folder before copying it, or explicitly import a selected old JSON file using `tools/migrate-saved-filters.py`; the original is retained and existing destination preferences are preserved.
- Rebuild or replace `SweetCherry.exe` to obtain its new Java search settings; replacing only the JAR cannot update an old native launcher.
- `server.port` is the primary listener and `server.http.port` is the optional additional HTTP listener; set `server.http.enabled: false` to use only the primary listener, and configure SSL before selecting HTTPS.
- Normal Maven packaging preserves existing private directories, while clean release staging rejects private saved filters, backups and replacement images.
