# SweetCherry 1.0.0 video çekim planı

Bu belge çekim senaryosudur; kaydedilmiş uygulama videosu değildir. Mevcut demo.ctb kullanılır. Yeni test turu veya özellik geliştirmesi gerektirmez. Ekran kaydı yapılırken örneklerin demo veritabanına ait olduğunu belirtin.

## Kısa tanıtım — yaklaşık 90 saniye

TTS metni: `intro-v1.0.0-tr.txt`. Türkçe ses, doğal hız; ürün adlarının telaffuzunu dinleyip gerekirse TTS girişinde fonetik olarak düzeltin. Süre ses hızına bağlıdır.

| Bölüm | Ekran |
| --- | --- |
| Amaç | SweetCherry başlığı ve demo.ctb açık masaüstü görünümü |
| İçerik | Demo içindeki farklı düğümlere geçiş; düzenleme menüsünü gösterme |
| Ağaç | Düğüm ve paylaşımlı düğüm konumları; yer işareti menüsü |
| Haritalar | Markmap ve Mermaid görünümlerinden kısa kesit |
| Export | PDF sihirbazı ve PDF görüntüleyicinin navigasyonu |
| Başlatma | Kontrol penceresi: hazır durumu, tarayıcı ve durdur düğmeleri |
| Kapanış | Release ve kurulum bağlantıları; otomatik yedek yok bilgisi |

## Kurulum ve kullanım — yaklaşık 4–5 dakika

TTS metni: `tutorial-v1.0.0-tr.txt`. Gerekli tıklamaları seslendirmeden daha yavaş yapın; indirme/başlangıç beklemelerini kısaltın. Ekrandaki yazı okunabilir boyutta olsun.

| Sıra | Çekilecek görüntü | Not |
| --- | --- | --- |
| 1 | GitHub v1.0.0 Release → Assets | Installer ve portable ZIP ayrımı |
| 2 | Installer klasör seçimi ve tamamlanma | Yazılabilir örnek klasör; kişisel yol yerine örnek kullanıcı |
| 3 | SweetCherry kontrol penceresi | Başlatılıyor → hazır; URL |
| 4 | Application Folder ve giriş ekranı | Parola dosyasının yalnız adını gösterin; içerik/parola görüntüsü kaydetmeyin |
| 5 | Demo Database seçimi | Paket CTBDATA/demo.ctb örneği |
| 6 | Ağaçtan birkaç demo düğümü açma | Demo'da bulunan içerikleri kullanın; olmayan özellik için örnek varmış gibi görüntü üretmeyin |
| 7 | Bookmark ve Harita menüleri | Markmap, Mermaid; Freeplane ikon seçenekleri |
| 8 | Düğüm ve Alt Düğümler PDF sihirbazı | Ayarları gösterip mevcut demo çıktısını açın; sol PDF navigasyonunu gösterin |
| 9 | allTenants ve kurulum kılavuzu | Kişisel bağlantı bilgileri görünmesin |
| 10 | Kontrol penceresinden durdurma | Browser kapatmak ile uygulamayı durdurmak arasındaki fark |

Videoda parola, kişisel veritabanı, dış sunucu kimlik bilgileri veya oturum çerezleri görünmesin. Demo editlerini göstermek isterseniz kopya demo kullanın; çekim kapsamı temel kurulum ve görüntüleme olarak da kalabilir.

## Video açıklaması

SweetCherry 1.0.0 — CherryTree CTB not veritabanları için açık kaynaklı web yardımcısı.

İndirme: https://github.com/turkerozturk/SweetCherry/releases/tag/v1.0.0
Türkçe kurulum: https://github.com/turkerozturk/SweetCherry/blob/v1.0.0/documentation/tr/installation.md
English installation: https://github.com/turkerozturk/SweetCherry/blob/v1.0.0/documentation/en/setup-and-run.md

Windows paketi x64 ve Java 17 içerir. SweetCherry otomatik yedek almaz.

Gerçek ekran kaydı için Windows'ta OBS Studio veya kullandığınız ekran kayıt aracından yararlanabilirsiniz. TTS sesini kayıt üzerine yerleştirin; ekranda görülen işlemlerle hizalayın. Bu hazırlıkta ses veya gerçek ekran videosu üretilmemiştir.
