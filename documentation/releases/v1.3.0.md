# SweetCherry 1.3.0

SweetCherry is an open-source web companion for CherryTree CTB note databases. This release adds embedded codebox editing, offline LaTeX rendering, content notes in Freeplane exports, and easier navigation and CTB export handling.

## Download and install

Windows 10/11 **64-bit** packages include **Java 17**; a separate Java installation is not required.

| Asset | Purpose |
| --- | --- |
| `SweetCherry-1.3.0-windows-x64-setup.exe` | Installation wizard, desktop launcher and shortcuts. Choose a writable folder. |
| `SweetCherry-1.3.0-windows-x64.zip` | Portable application. Extract the complete folder before running `SweetCherry.exe`. |
| `SweetCherry-1.3.0-notices.zip` | Third-party licenses and attributions, also included in both application packages. |
| `SHA256SUMS.txt` | Checksums for the installer, portable ZIP and notices ZIP. |
| `windows-bundle.json` | Application version, exact build commit and bundled Java information. |

GitHub's automatic Source code ZIP/tar.gz archives contain source, not a ready-to-run application. Linux/Raspberry Pi users can build with JDK 17 or newer. The Windows EXE and bundled Windows Java are not Linux binaries. macOS scripts have not been verified on a physical Mac.

## Rich text, codeboxes and LaTeX

- Add embedded codeboxes at the cursor and edit an existing codebox's plain source and language. These are separate objects inside a rich-text node, distinct from a node whose entire content is code.
- The searchable language list starts with Plain Text, followed by alphabetically ordered languages with icons. New boxes default to left alignment, 300×150 pixels and no line numbers. Existing dimensions and flags are preserved.
- Codebox changes support undo/redo and Save and continue. They are written only when the main editor is saved; unchanged saves preserve the node's modification date. Code is not executed. Editing is plain text; normal display retains the existing syntax highlighting setting.
- Render supported CherryTree LaTeX objects offline using JLaTeXMath: PNG for web content, vector outlines in PDF where possible, and PNG fallback. Monochrome PDF output uses PNG. Unsupported expressions fall back to escaped source text; original TeX attachment data and editor protections are preserved.
- Translate image, table and codebox browsing pages into Turkish/English, including empty lists. JLaTeXMath and font license notices are included in the distribution.

## Navigation and layout

- **Go to Node ID** in the Application menu opens a node by its occurrence ID, with clipboard paste and searchable, styled bookmark shortcuts. Read-only users can navigate without move permissions.
- **Move to** gains clipboard paste and a bookmark destination picker with a title filter. Selecting a shortcut fills the ID; the explicit Move action still performs the operation.
- Remember the desktop `/tree` pane width across tabs. The configurable `myapp.tree.default-width` defaults to 600 pixels; resizing is constrained to 20–1900 pixels and the available viewport. Other splitters are unchanged.
- Compact bookmark date/order columns, keep drag handles beside their sequence numbers, and simplify column headings.

## CTB and mind-map exports

- **Every CTB export now adds a dated, bold top-level source container**, with the exported node/branch below it. Its title records the source database name and selected source occurrence ID; its timestamps are new, while copied node timestamps are preserved.
- Remap supported internal links to included occurrences. Links to missing source targets or targets outside the selected export are redirected to the container, which lists their source type, target ID/name and link text. Shared hierarchy is preserved. Repeated exports have separate containers.
- Confirm each CTB export before starting. Translate export results and exported-file actions; provide a return link after file deletion.
- Add an optional **Include content** setting to Freeplane/FreeMind export, disabled by default. Content is exported as plain-text node notes, with link destinations and text representations of tables/codeboxes and image/attachment metadata. Existing icon-only, icon-reference and ZIP options remain available.
- Translate node-information Yes/No values and content-type labels; hide the raw rich-text flag row from the rendered panel.

## Upgrade from 1.2.0

Stop SweetCherry. Preserve your CTBs, tenant configs, external YAML, `login-credentials.properties` and exports. Extract/install into a separate writable folder, then deliberately copy your own data/configuration across. Do not overwrite notes/passwords with demo files or merge old/new Java runtime folders. External YAML overrides still take precedence; omitted new settings have defaults.

**SweetCherry does not create automatic backups.** Back up important data before editing or importing. Do not write to the same CTB simultaneously from SweetCherry and CherryTree. SweetCherrySync is separate; later synchronization can overwrite edits to its target.

Exported CTBs now have an extra source-container level. The container includes the source database display name and diagnostic node names/link text: review these before sharing an export. CTB import retains its existing preview and validation rules; export is not synchronization or deduplication.

## Validation and limitations

The maintainer confirmed the new functionality manually and reported successful GitHub Actions on the final feature commit (513 passing Java tests in Actions; 515 locally). The Windows release packages are built from the **v1.3.0 tag**, including workflow tests and installer/launcher checks without system Java. Relevant editor JavaScript tests and Chromium desktop/mobile viewport checks passed during implementation; viewport checks are not physical-device certification. Two existing duplication JavaScript test failures were reproduced on the unchanged baseline and remain follow-up test maintenance; they are outside the passing editor subset.

LaTeX supports JLaTeXMath's math subset, not arbitrary TeX documents/packages; external resource commands are blocked and rendering limits apply. Codeboxes are edited without live syntax highlighting. Clipboard HTML/images depend on browser formats and permissions; some actions require HTTPS or localhost, and Flameshot compatibility remains unresolved. Content filtering searches raw `node.txt`; browser Back after POST search may request resubmission. The previously observed isolated MariaDB 1020 record-change conflict remains an observation if it recurs; conflict protections were not removed.

SweetCherry is GPL-3.0-or-later. Third-party components retain their own licenses; notices are included in both Windows packages and the notices ZIP.
