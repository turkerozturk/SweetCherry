# SweetCherry 1.2.0

SweetCherry is an open-source web companion for CherryTree CTB note databases. This release adds CTB import, more comfortable editing and navigation, and clearer import/configuration diagnostics.

## Download and install

Windows 10/11 **64-bit** packages include **Java 17**. A separate Java installation is not required.

| Asset | Purpose |
| --- | --- |
| `SweetCherry-1.2.0-windows-x64-setup.exe` | Installation wizard, desktop launcher and shortcuts. Choose a writable folder. |
| `SweetCherry-1.2.0-windows-x64.zip` | Portable application. Extract the complete folder before running `SweetCherry.exe`. |
| `SweetCherry-1.2.0-notices.zip` | Third-party licenses and attributions, also included in both application packages. |
| `SHA256SUMS.txt` | Checksums for the installer, portable ZIP and notices ZIP. |
| `windows-bundle.json` | Application version, exact build commit and bundled Java information. |

## Import and organize notes

- Import a CTB listed on `/exportedFiles` into the active writable database after reviewing table counts and confirming. The source is read-only; imported roots are appended to the target tree. Hierarchy, shared groups, objects, bookmarks and timestamps are preserved, with new IDs and remapped internal node links.
- Configurable import byte/record limits default to **64 MiB and 200,000 records**. If a limit is exceeded, the preview shows measurements and where to change the settings. Invalid internal links list the source title, IDs, table/field and missing target before any import write.
- **Move to**, next to Delete, accepts a parent node ID and moves the selected occurrence with its subtree to that parent's last position. Real and shared parents are supported; `0` selects the database root. Self/descendant moves and stale tree snapshots are rejected.
- Reorder bookmarks using touch, mouse or keyboard. Recently modified/added pages offer configurable row counts, node icons and an information drawer. The database welcome view links to these pages and bookmarks.

## Editing and reading

- Plain-text undo/redo, unsaved-change protection in both editors, and **Save and continue**.
- Persistent content zoom controls in View Mode. Rich-text controls are grouped in a resizable desktop sidebar or a mobile drawer, keeping the writing area available and preserving text selection.
- List-symbol buttons, selected-URL linking, visible table borders and resizable editing areas.
- An explicit clipboard action and a separate public-URL content importer for supported rich text, PNG/JPEG images and simple tables. Existing browser paste remains available; imports are editable and can be undone before saving.
- Browser language is used initially unless configured otherwise. Additional Turkish/English translations, mobile navigation help and an empty-content notice make the interface clearer.

## Configuration and fixes

- Choose a database icon visually in the connection wizard; use it beside database names and applicable mind-map roots.
- CTB selection lists put recently modified files first, followed by other data sources alphabetically. The data-source table is alphabetic and shows CTB filesystem modification dates.
- Consistent node timestamp rules for editing, creation, movement, bookmarks and shared-node operations; no-op content saves leave the modified date unchanged. These rules are documented for incremental synchronization.
- Correct Actuator version reporting, Windows SQLite file-URI handling, mobile object IDs and PNG/JPEG uploads with missing MIME types.
- Clearer node title/icon positioning and less unused space above content.

## Upgrade from 1.1.0

Stop SweetCherry first. Preserve your CTBs, tenant configs, external YAML, `login-credentials.properties` and exports. Extract/install into a separate writable folder and deliberately copy your own data/configuration across. Do not overwrite your notes or passwords with demo files, and do not merge old/new Java runtime folders. External YAML overrides still take precedence; new settings have defaults when omitted.

**SweetCherry does not create automatic backups.** Back up important data before editing or importing. Do not write to the same CTB simultaneously from SweetCherry and CherryTree. SweetCherrySync is a separate tool; later synchronization may overwrite edits to its target. CTB import creates copies and is not synchronization or deduplication.

## Validation and limitations

The maintainer reported **471 passing Java tests**, manual checks of the new functionality, and a successful Windows packaging run on the final feature commit. Release assets are rebuilt from the **v1.2.0 tag** using GitHub Actions; that workflow runs tests and installer/launcher checks without system Java. Relevant move-control JavaScript tests and Chromium desktop/mobile viewport checks also passed during implementation; viewport emulation is not physical-device certification.

Clipboard HTML/images depend on the browser, clipboard formats and permissions; some actions require HTTPS or localhost. Flameshot clipboard compatibility remains unresolved; working image-file/other clipboard paths are retained. URL import supports selected content rather than complete browser-page fidelity. Content filtering still searches raw `node.txt`; Back after a POST search may require form resubmission. Existing CTB export does not rewrite node IDs embedded in text links; the new CTB import remaps supported internal links and rejects external-to-source node targets. Codebox editing and other rich-text refinements remain follow-up work. An isolated MariaDB 1020 record-change conflict remains an observation if it recurs; conflict protections were not removed.

SweetCherry is GPL-3.0-or-later. Third-party components retain their own licenses; notice files are included in both Windows packages and the notices ZIP.
