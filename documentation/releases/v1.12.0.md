# SweetCherry 1.12.0

Prepared on **20 November 2026**. This release improves reusable content, reading/navigation, attachment/image tools and backup controls. Java **17+** and the existing CTB schema are retained.

## Changes since 1.11.0

- Added attachment text previews with encoding selection and syntax highlighting, paged hex views, and ZIP/TAR/TAR.GZ archive listings.
- Added remembered linked-content views that embed internal-link targets inline, with an option to hide source labels.
- Added title-contains search with selectable node paths and IDs to the internal-link and Move to dialogs.
- Added PDF options for linked-node content and continuous output, with linked content rendered inline without source labels.
- Added automatic readiness detection that reopens SweetCherry after a restart.
- Added persistent, independent confirmation toggles for node creation, duplication and deletion.
- Added configurable node-content backgrounds through YAML, System settings and an instant color picker.
- Localized import file selectors and preserved intentional leading blank lines in rich-text content.
- Added keyboard navigation in the node tree and retained navigation focus after moving a node.
- Added automatic icon filtering when the selected category changes.
- Added in-place node-title editing and reorganized the content toolbar for quicker access.
- Added scheduled-backup status, schedule removal and a button to enable automatic backups for the active database.
- Added split view for reading two nodes side by side.
- Added saved searches as virtual tree branches, enabled by default.
- Added read-only web bookmark nodes with sanitized page previews and an external-open link.
- Added image annotations with shapes, arrows, freehand drawing, undo/redo and confirmed PNG replacement for PNG, JPEG and BMP sources.
- Added confirmed sorting of immediate child nodes by name, creation date or modification date in either direction.
- Added original image dimensions, megapixel counts, source format, color depth and alpha-channel information to the gallery.
- Documented how to build the Windows launcher locally without GitHub Actions.

## Upgrade and behavior

Stop SweetCherry and other CTB writers, and keep separate backups of databases, external YAML, tenant definitions, credentials and saved filters. Install/extract into a new writable folder; transfer private data deliberately and do not replace private CTBs with demo files. Existing external configuration overrides bundled defaults. The preparation adds no dependency or CTB schema migration.

- Saved-search branches are enabled by default; their appearance setting can disable them. They are virtual query results, not additional stored node occurrences. Saved filters remain external configuration and need their own backup.
- Linked-content display preferences are retained across navigation. PDF linked-content export omits source labels; continuous node output is the default, with a separate option to start each node on a new page. Recursion and oversized/unsupported content remain bounded.
- Image information describes the stored source (not the resized preview): pixel dimensions, megapixels, format and, when the image reader exposes them, bits per pixel and alpha-channel presence. An alpha channel does not imply that any pixel is transparent; no print DPI is inferred. Information is read lazily with previews; unavailable values remain a dash.
- Image annotation supports static PNG/JPEG/BMP sources and always saves flattened PNG pixels after explicit confirmation. JPEG/BMP named attachments receive a `.png` extension, file size may increase, and other source metadata is not retained by conversion; JPEG EXIF orientation is applied. Download the original or back up the CTB first: editor undo history is not a persistent original-image archive. Limits remain 16 MiB, 8192 pixels per edge and 12 million pixels for annotation.
- Child sorting changes only immediate sibling order, uses master metadata for shared children and preserves child timestamps. Equal sort keys retain their order; case-insensitive names use lexicographic rather than numeric/locale-specific sorting. A changed list rejects stale confirmation. The change is persisted in CTB.
- Web bookmark previews apply only to eligible read-only, empty URL-named nodes. Network requests and sanitized output are bounded; scripts and in-preview links do not run. Some websites cannot be fetched or rendered faithfully. Use the external-open icon for the original website. [Details](../en/web-bookmark-nodes.md).
- Mutating operations retain administrator/writable-source, CSRF and current-tenant checks. Enabling a schedule is limited to eligible CTB tenants; removing a schedule does not interrupt an already-running backup.
- Reminder/alarm behavior from 1.11.0 is unchanged: pages must remain open for in-page alerts; closed browsers and sleeping computers cannot guarantee notification delivery.

## Validation and release steps

The maintainer reported **1079 Java tests, zero failures/errors and two skipped tests** before this preparation, plus successful manual child-sorting checks. These results are not validation of the preparation commit or final packages. JPEG annotation was not manually exercised by the maintainer. Preparation checks passed **27 targeted Java tests** using cached dependencies and **292 JavaScript tests**, plus version/document-link and patch checks. No manual browser validation was performed during preparation. Full Maven packaging must run locally/CI because the preparation environment cannot resolve Maven Central.

Run `mvnw.cmd clean package`, JavaScript tests, CI and the tagged **Portable distribution (Windows builder)** workflow. Verify notices against the final packaged JAR with `python packaging/update-jar-notices.py --check`. Test both packages and checksums before publishing.
